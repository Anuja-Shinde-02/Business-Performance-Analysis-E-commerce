##Business Performance Analysis for an E-Commerce Retailer

#Section 1 — Project Charter

*Background
An e-commerce retailer has collected customer and order data over three years. Although transactional data is available, the business lacks a structured analysis to understand sales performance, customer purchasing behavior, product performance, and regional trends.

*Business Problem
The management team wants to understand how the business is performing and identify opportunities to improve revenue, customer engagement, and product strategy through data-driven decision-making.

*Project Objective
Analyze customer and order data using SQL and Power BI to answer key business questions, uncover trends, and provide actionable recommendations for business growth.

*Scope
- Assess data quality before analysis.
- Analyze revenue trends.
- Evaluate customer purchasing behavior.
- Identify top-performing products and categories.
- Analyze geographical sales performance.
- Build an interactive Power BI dashboard.
- Present actionable business recommendations.

#Section 2 — Understanding the Dataset

*Dataset Overview
1. Customer Table
| Column        | Description                                                    |
| ------------- | -------------------------------------------------------------- |
| customer_id   | Unique identifier for each customer                            |
| first_name    | First name                                                     |
| last_name     | last name                                                      |
| country       | Country where the customer is located                          |
| state         | State where the customer is located                            |
| city          | City where the customer is located                             |
| score         | Customer score used for segmentation (contains missing values) |

2. Orders Table
| Column      		   | Description                |
| -------------------- | -------------------------- |
| order_id     	       | Unique order ID            |
| order_date           | Date of purchase           |
| customer_id          | Customer placing the order |
| product_name		   | Product  purchased         |
| product_category     | Product category           |
| quantity    		   | Quantity purchased         |
| sales    		       | Sales amount               |
